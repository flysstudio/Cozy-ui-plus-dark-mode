## 暗色版做了什么 / What it does

### 🎨 界面贴图压暗 · Darkened GUI textures

- 共 **818 张**界面贴图，在原版基础上整体压暗，**保留原本的观感、布局和细节**
- *818 GUI textures darkened from the original — the look, layout and details are all preserved.*

### 🧩 覆盖范围 · Coverage

| 命名空间 / Namespace | 贴图数 / Textures |
| --- | --- |
| `minecraft`（原版界面） | 543 |
| `jei`（物品管理器，含暗色适配） | 53 |
| `nochatreports` | 48 |
| `roughlyenoughitems` | 37 |
| `inventoryhud` | 35 |
| `voicechat` | 30 |
| `dynamiccrosshair` | 21 |
| `modmenu` | 13 |
| `emi` | 7 |
| `xaeroworldmap` | 6 |

### 🔧 JEI 暗色适配 · JEI dark support

- 内置 **JEI 的暗色适配**，解决 JEI 与 CozyUI+ 一起用时界面不协调的问题
- *Built-in JEI dark support, so JEI and CozyUI+ look consistent together.*

## 更新日志 / Changelog

### v1.0.0 —— 首个发行版 / First release

**中文**
- 基于原版 CozyUI+ 制作暗色版本：界面贴图整体压暗，保留原本的观感与布局
- 覆盖原版界面 + 常用 mod 界面（JEI / REI / EMI / NoChatReports / InventoryHUD / 语音聊天 / ModMenu / Xaero 世界地图 等）
- 内置 **JEI 暗色适配**，装上就不会出现 JEI 界面突兀的问题
- 适配版本：**1.20.1 – 26.3**

**English**
- Initial dark version based on the original CozyUI+: GUI textures darkened, original look and layout preserved
- Covers the vanilla UI plus common mod UIs (JEI / REI / EMI / NoChatReports / InventoryHUD / voicechat / ModMenu / Xaero's World Map, etc.)
- Includes built-in **JEI dark support**
- Supported versions: **1.20.1 – 26.3**
